技術選型

純前端、靜態部署、行動裝置優先，三個合理方向

A

SvelteKit + Vite（推薦）

Bundle 最小、reactive state 寫起來最直覺、適合畫布密集的小品。

  • SvelteKit static adapter → 純靜態站
  • Canvas API（畫筆）+ SVG（背景符咒框架、太陽、印章）混合
  • html-to-image 做分享圖輸出
  • lunar-javascript 處理農曆換算
  • 部署：Cloudflare Pages / Netlify / GitHub Pages
B

React + Vite

最主流、最多資源、之後找協作者最容易。Bundle 比 Svelte 大。

  • Vite + React + TypeScript
  • 同樣 Canvas + SVG 混合策略
  • 部署同上
  • 適合你之後想長期維護或加功能
C

Vanilla TS + Canvas

無框架、最輕、零依賴啟動。狀態管理要自己寫，對於這個 App 規模不算太麻煩。

  • Vite + TypeScript + 純 DOM/Canvas
  • 體積最小、啟動最快
  • 沒有 reactive state，需要手動同步
  • 適合你想「就這一個專案、不擴張」的情況

推薦 A —— 對小品最舒適，Bundle 對手機網路友善。但你如果之後想加功能、找協作者，B 更穩。
