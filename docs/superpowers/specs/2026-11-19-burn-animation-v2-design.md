# 燒紙動畫 v2 — 寫實燒蝕設計

**日期**：2026-11-19
**狀態**：Approved
**範圍**：`BurnEffect.svelte`、`Burn.svelte`

## 意圖

使用者希望燒紙更「華麗」，方向選定為**寫實**：一張紙從角落被火吃掉、邊緣發紅焦黑、火焰與火星沿燒蝕前緣移動，最後整張紙燒盡只剩灰燼。燒紙是產品三大核心之一（「燒的瞬間爽」）。

## 目標 / 非目標

- 目標：孔洞從隨機一角擴散；不規則焦邊；餘燼發光閃爍；火焰、火星、煙跟著前緣；結尾紙張消失、灰燼飄落；總長維持 4 秒。
- 非目標：3D 紙張捲曲、音效、改變分享圖（仍為完整符紙）。
- 反目標：低階 Android 掉幀；新增套件。

## 限制

- iOS Safari 15+、Android Chrome 90+。
- 保留：背景分頁跳結尾、`prefers-reduced-motion` 顯示靜態結尾並 1.2 秒後前進、震動回饋、`done` 事件。

## 做法比較

1. **CSS + SVG clipPath（採用）**：rAF 每幀更新一條不規則 path 作為符紙的 clipPath，同一條曲線疊焦邊與餘燼描邊；火焰／火星／煙為少量 DOM 元素。無套件、低負擔。
2. Canvas 粒子系統：火更密，但程式量與效能風險高。
3. WebGL shader：最逼真，對 4 秒迷因工具過重。

## 設計

- 孔洞曲線：以起火角為圓心，`r(θ, t) = R(t) · (1 + 0.12·sin(5θ+φ₁) + 0.07·sin(11θ+φ₂) + 0.04·sin(23θ+φ₃))`，φ 與起火角每次隨機。`R(t)` 以 ease-in-out 從 0 增至 `requiredRadius(shape)`：對每個穿過紙面的射線取「射線離開紙面的距離 ÷ 該角度的鋸齒係數」的最大值 × 1.02，使紙在 t ≈ 0.9 剛好燒盡（固定 1.35 × 對角線會讓紙在中位數 2.6 秒就燒完、空等 1.4 秒）。
- 符紙座標系 300×400；clipPath 用 `objectBoundingBox` 並以 transform 縮放；`clip-rule: evenodd`（外框矩形減孔洞）。
- 焦邊：同曲線深褐色寬描邊 + 模糊；餘燼：橘黃細描邊 + 發光，透明度閃爍。
- 火焰 8 個、火星約 30 顆、煙 4 朵、灰燼碎片約 12 片，皆以 CSS keyframes 動畫，位置由 rAF 貼到前緣。
- 時間軸：0.0 起火點＋震動；0.3 孔洞開始；1.0 火星與煙；2.4 柔和閃光；3.3 火焰縮小；3.8 燒盡、餘燼熄滅、灰燼飄落；4.0 `done`。
- `Burn.svelte`：符紙外加容器掛 `clip-path: url(#burn-clip)`；移除方形橙色 box-shadow。

## 留給實作決定

火焰造型細節、火星顏色漸層、閃光強度。
